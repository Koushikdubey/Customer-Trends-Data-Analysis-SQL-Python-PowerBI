# Dataset Documentation

This folder contains the dataset used for the Customer Shopping Trends Analysis project.

The dataset supports exploratory data analysis in Python, SQL-based business analysis, and visualisation in Power BI.

## Dataset Details

- **Format:** CSV or Excel, depending on the source file.
- **Purpose:** Analyse customer shopping behaviour, purchasing patterns, and product preferences.
- **Usage:** Data cleaning, exploratory analysis, SQL queries, and dashboard development.
